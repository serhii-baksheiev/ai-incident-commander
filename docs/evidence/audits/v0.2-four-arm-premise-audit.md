# v0.2 four-arm premise and fairness audit (AIC-122)

Written on 2026-09-29, on `main` at `ab5e047`, before any paid calibration run.
AIC-122 requires this audit to run on the calibration partition only, after
AIC-123 to AIC-126 land and before AIC-121 may run. It checks two things. The
first is whether the claimed investigation cycle is executable code. The second
is whether the four-arm comparison measures what the preregistration says it
measures.

Each row gives a verdict and the test that backs it. **Holds** means a named
test pins the claim. **Gap** means the premise fails and the row names what
closes it. **Owner** means the row needs a decision this audit cannot make.
Where an evidence cell says a reviewer measured something, that measurement
lives in the review, not in the repository.

## The hold-out premise

The four-arm preregistration assumes an untouched hold-out. The
`docs/evidence/final-evaluation/` records say something narrower.

- **Four `complete` records did not reach a hold-out example.** Their model arms
  made 4, 3, 15 and 23 provider calls (`05714e89391a`, `b5a0121d72b6`,
  `872ef36dea33`, `cf68c16c8592`). The final-evaluation plan puts every
  calibration example before the first hold-out example:
  `packages/evals/src/benchmark-evaluation.ts` spreads
  `BENCHMARK_SCENARIO_PARTITIONS.calibration` ahead of `.holdout`. At three runs
  per scenario that is 24 calibration records. On those records' commits, each
  graph-model record's first reasoning node is a model role, so each record costs
  at least one call. 23 calls cannot reach record 25. The plan keeps the
  partition's scenario order and lists each scenario's runs together
  (`scenariosForPartition` and `buildBenchmarkPlan` in the same file).
- **Three `claimed` records state in their own `interruption` notes that the
  model executed against hold-out scenarios** (`145a2afba7b8`, `587842baeabb`,
  `6362d883decd`). None of them carries a usage figure, so the bound above
  cannot confirm or refute that statement.
- **No hold-out score was ever produced.** Every model arm in these records is
  unreportable.

This conflicts with `docs/v0.2-exit-gate.md`'s opening block, which says the
hold-out "has been executed on the reference model" and cites `872ef36dea33` and
`cf68c16c8592`. Their call counts are below the bound. The exit-gate document
belongs to AIC-19 and is not edited here.

**Owner decision:** keep the hold-out and disclose these attempts in the v0.2
result, or replace the two hold-out scenarios. This is needed before the final
hold-out, not before calibration.

## Addendum, 2026-09-29: row 14c after AIC-143

AIC-143 tells the challenge role the requests the investigation can execute.
Supplement 10 registers the change and the prompt version it moves,
`reference-roles-prompt-v0.6`. No provider call was made.

- **The graph can execute a discriminating challenge test** on
  `challenge-keeps-leader` (row 14a), and **the role is now told the vocabulary
  that test is written in.** The sentence is derived from the route table and
  the domain enums, and names exactly the requests the planner can form: see
  request-vocabulary.test.mjs › "routeRequestVocabulary(INVESTIGATION_ROUTES)
  names exactly the (tool, key, value) triples planInvestigation can form over
  every ExpectedObservation variant, in both directions, and latency appears in
  no entry’s values". The graph arm passes it to the role: see
  lane-arms.test.mjs › "modelNodes(record, port).challenge_hypothesis's captured
  system prompt contains describeRequestVocabulary(routeRequestVocabulary(INVESTIGATION_ROUTES))".
- **Whether the model chooses that test is not a premise.** The sentence names
  no scenario, service or evidence, and does not say which request answers
  where: see request-vocabulary.test.mjs › "the vocabulary for
  INVESTIGATION_ROUTES names no replay-corpus value: no scenario id, evidence
  id, annotation subject, or recorded input value". A calibration run in which
  the graph-model arm fails `challenge_effect` now reads as the model not
  proposing a discriminating test it was able to name and the graph was able
  to run. It is no longer a structural impossibility.
