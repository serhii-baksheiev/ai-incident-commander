# Preregistration supplement 4: the observation table `observation-annotations-v1`

Written on 2026-09-28, before any prediction-derivation template exists and
before any paid run. It records the owner's AIC-123 decision D3 (Jira AIC-123,
2026-09-25): typed facts for the corpus come from a separate, versioned
sidecar table; each fact follows from its own evidence item's prose only; the
table is digest-frozen before any prediction-derivation template exists, and
it is blind-reviewed. The fixtures stay unchanged.

It adds a row to `v0.2-four-arm.md`'s table "What is fixed before any result
exists". Every row of `v0.2-four-arm.md` and supplements 1 to 3 stands as
registered.

| item | value |

## How the table was made

- **One row per served evidence item.** A row is keyed by the v2 replay
  identity of the call that served the item, plus the item's id. The identity
  alone is not a key, because one identity serves more than one evidence item.
  See observation-annotations.test.mjs › "carries exactly one row per distinct
  (replay identity, evidence id) pair the ok corpus serves, none missing and
  none extra" and › "the ok corpus really serves the same replay identity for
  more than one distinct evidence item, so identity alone cannot key this
  table".
- **The readers saw prose only.** Two independent readers were each given a
  packet: a closed fact vocabulary with reading rules, then every distinct
  statement of the corpus, ordered by the statement's sha256. The packet holds
  no evidence id, no scenario id, no evidence source and no ground truth. See
  observation-annotations.test.mjs › "the packet carries no evidence id, no
  scenario id, and no evidence source string — the reader sees prose only" and
  › "sha256 of buildObservationReviewPacket() equals the digest the review
  record pins".
- **Facts are the intersection.** A fact is in the table only if both readers
  wrote it. The review record, `docs/evidence/observation-annotations/review-v1.json`,
  keeps both readers' answers. See observation-annotations.test.mjs › "every
  row's facts equal the deep-equality intersection of the two readers' facts
  for that row's own packet sentence number".
- **A fact names only what its sentence names.** See
  observation-annotations.test.mjs › "every fact parses as a well-formed
  ObservedFact, and its subject appears in its own row's statement" and ›
  "names no REPLAY_SCENARIOS id anywhere in the serialized table".
- **No fact can read as absent.** No sentence claims an exhaustive check. See
  observation-annotations.test.mjs › "no fact in the table reads as absent
  under observedPresence, because no sentence claims an exhaustive check".

## What this commits to

- The prediction-derivation templates (AIC-124) are written after this
  supplement is merged. They are not fitted to this table: a template is
  derived from a mechanism's definition, never from which facts the corpus
  happens to carry.
- A change to the table is a new, dated, reviewed version with its own
  supplement, never an edit to `observation-annotations-v1`.
- The table is registered here before anything reads it. How it reaches the
  investigation, and that the arms see the same evidence, is registered in the
  supplement that wires it, before AIC-121 runs.
